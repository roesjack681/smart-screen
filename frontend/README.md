# 生产安全感知平台（前端大屏）

Vue 3 深蓝大屏，无登录。当前接入总览主页和生产安全预警，数据均为本地 Mock。

## 顶栏

- 总览：保留原有园区总览。
- 生产安全预警：默认原料仓储：4库192垛热力图、批次档案、温检与存放提醒；可切换生产工艺的8个仪表测点、3类泄漏事件，并共用全局告警。
- 危险作业监控 / 动态风险评估：保持原有空白内容区。

## 启动

```bash
npm ci
npm run dev
```

http://localhost:5173

## 本地部署

在本目录执行以下命令，无需后端服务：

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 4174 --strictPort
```

打开 http://127.0.0.1:4174/dashboard?view=production 。关闭终端或按 Ctrl+C 停止服务。

## 演示生产预警

- 任意页面顶部“演示控制台”可选择设备并注入高限、低限、严重超限、快速升降或离线异常。
- 根组件持续采样，每秒更新。默认超限持续 2 秒、离线 5 秒触发黄色预警，离线 15 秒升级红色报警；斜率按最近 15 秒样本实际时间差计算绝对值。
- 弹窗和黄/红色闪烁边框覆盖所有页面。确认后关闭弹窗，未解除时保留边框；收起后 60 秒再次提醒，红色升级会立即重新提醒。黄色信号恢复自动解除；红色信号恢复后在详情记录现场复核才能解除。
- 同一设备重复注入当前异常保留确认状态，不重复弹窗；切换不同异常会结束该设备上一轮演示，保留历史记录并在新异常满足条件后再次弹窗，其他设备不受影响。
- 控制台支持一键温度+压力并发超限，以及香精/酒精大面积泄漏、地埋罐泄漏检测信号。
- “恢复全部演示数据”恢复所有模拟信号，红色事件仍需人工复核。规则按测点保存到当前浏览器；事件与复核记录仅保留在当前运行会话。声音默认关闭，可在顶栏启用。
- 设备维护、维护模式和工单功能已移除。
