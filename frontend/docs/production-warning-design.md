# 生产安全预警：仓储与工艺设计

本版以《原料贮存、养护和发放控制程序》补全原料仓储业务，同时保留 M5 工艺规则表对应的提取工艺、乙醇储罐、可燃气体和泄漏事件。其他页面不变，无设备维护、无后端。

## 业务层级与页面

- 库房 → 排/列 → 垛位 → 原料批次 → 抽检温度序列 → 温检记录与异常处置。
- 默认展示“原料仓储”：4个模拟库区，每库6排×8列，共192垛；库区用途分别为原料贮存、备料周转和在库周转。名称、布局、批次和环境数据均为Mock，并非真实库房平面图。
- 顶部展示库区环境温度、相对湿度；热力图按温度着色，点击格子查看该垛批次、入库日期、最近温检、检查频次与趋势。
- 温检到期、备料库存放超期以待办链接定位到垛位；登记温检更新模拟检查日期，不代表告警已解除。
- “生产工艺”切换至原有8个工艺/储罐/气体测点及3类泄漏事件；两类业务共用事件中心和根组件全局提醒。
- 热力图为模拟实时抽检均值序列。资料规定的是人工抽检与记录频次，不能据此声称现场每垛已有实时传感器。

## 仓储资料的具体映射

来源：《原料贮存、养护和发放控制程序.pdf》（QG/ZY-BC-002-2025）。页码以下为PDF物理页码，括号为页脚页码。

| 资料定位 | 资料要求 | 本版体现 |
| --- | --- | --- |
| 第4页（2）§5.2.3 | 堆垛后悬挂标识牌，填写保管卡 | 垛位编号、原料种类、批次及入库日期；均为模拟档案 |
| 第4页（2）§5.2.4 | 备料库连续存放不超过1个月 | 仅C号备料库按入库日期增加1个日历月判定超期，不扩大到所有仓库；显示存放待办 |
| 第5页（3）§5.3.1 | 按月安排垛位养护、在库检查等 | 按垛位显示温检到期提醒与模拟温检登记；未实现整套月计划系统 |
| 第5页（3）§5.3.2 | 每天14—16时记录仓间温湿度，通风/除湿前后亦需记录 | 库区环境温湿度展示及资料说明；未提供的技术要求不自行编造温湿度合格区间，也未把实时刷新等同于登记完成 |
| 第5页（3）§5.3.4.2 | 4—10月每周检查，其余时间每半月检查 | 当前模拟检查安排采用季节基础频次（半月按15天实现；非杀虫期间前提需实际系统提供） |
| 同条款 | 包心≥32℃每两天检查；≥35℃每天检查 | 黄色检查加密提醒，35℃本身不会直接按工艺严重超温判红 |
| 同条款 | 包心平均温度高于贮存环境2℃，每天检查 | 将垛位模拟值解释为抽检均温，与所属环境温度比较；严格大于2℃生效 |
| 同条款 | 均温超过环境4℃，按不合格品程序处理，环境异常变温/高温天气入库除外 | 严格大于4℃且非例外时生成红色待复核事件；提供模拟例外条件开关，例外情形仍每日检查 |

资料还涉及来料接收抽检、虫害防治、堆垛间距与层数等；当前没有对应实时数据，未把它们伪装成在线检测结果。特别是来料>35℃的接收限制不与在库≥35℃的检查频次混用。

## 提醒与恢复

黄色/红色是Demo处置优先级，热力图颜色则表示温度大小，两者不是区域四色风险等级。仓储32/35℃依据资料固定；工艺报警定值、2秒持续判定、通信超时与屏幕闪烁是演示配置。

- 仓储或工艺异常都由应用根部持续判定，在总览、危险作业、动态风险等任意页均可弹窗并显示黄/红闪烁边框。
- 确认仅收起弹窗，未解除时边框保留；同设备重复当前模拟异常不重弹，切换不同异常结束上一轮模拟并再次提醒。
- 黄色恢复后解除；红色满足恢复条件后仍须填写现场复核人和结果才能解除。确认仓储温差红色事件同时确认该垛当时的温检提醒。
- “环境例外”是模拟复核输入，不等于证明现场安全；温差事件可进入恢复待复核，温检每日要求仍保留。
- 事件和温检登记只保存在当前页面会话，刷新重置；工艺数值规则保存在浏览器。

## 工艺来源与边界

《M5-香料工程中心车间风险等级动态识别规则与判定口径.xlsx》规则4—12用于可燃气体、提取温压液位、乙醇储罐和泄漏事件。工艺数值未在附件提供，仍标为演示配置。危险作业制度用于理解处置背景，不新增危险作业页面；风险分级程序不在本模块展开LS/LEC区域评估。
